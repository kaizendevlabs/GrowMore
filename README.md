\# Grow More Management System



Grow More is an offline/local AMC and SIP Management System designed to help an office manage investor information, SIP records, payment tracking, due SIPs, and reports efficiently.



\## Features



\- Login Management

\- Investor Management

\- SIP Management

\- Payment Tracking

\- Due SIP Management

\- Report Management



\## Technologies Used



\- HTML

\- CSS

\- PHP

\- MySQL

\- XAMPP



\## Project Type



Offline / Local Management System



\## Purpose



The main purpose of Grow More is to:



\- Manage investor information

\- Track SIP and lump sum investment records

\- Monitor SIP payment status

\- Identify due and upcoming SIPs

\- Generate useful reports

\- Improve office management and record keeping



\## System Workflow



The system follows a simple workflow:



\*\*Track → Monitor → Alert → Report\*\*



\## Important Note



Grow More is an offline/local management system.



It is \*\*not\*\* an online investment platform and does not provide:



\- NSE/BSE integration

\- Bank transaction integration

\- Payment gateway

\- NAV calculation

\- Units calculation

\- Profit/Loss calculation

\- Investment advice
